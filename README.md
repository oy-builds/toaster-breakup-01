# Unplugged: A Smart Toaster's Breakup Line

One line: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch — and discovers four years of unemptied crumb tray. Running `main.ts` writes the line to `/output/entry.txt`.
